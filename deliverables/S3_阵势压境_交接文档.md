## 2. 当前问题（你最关心的）

**症状**：debug 面板显示 `gameMode: boss`，点「练气突破」进入的是 legacy Boss 战，而不是 S3 阵势压境。

**真正根因**：`patch-s3.cjs` 漏改了一个关键位置——`Game.ts` 第 8583-8589 行 `initializeThunderGeneralBoss()` 里的 if-else 链。这段代码把所有"非 bossReactive/strategySlice"模式强制重置为 `boss`，**包括 bossFormation**。

调用链：
1. 构造函数第 443-444 行：`this.gameMode = "bossFormation"` ✓
2. 第 475 行：`initializeThunderGeneralBoss()` 被调用
3. **第 8588 行**：`this.gameMode = "boss"` ← 把 bossFormation 强制重置回 legacy
4. 第 8621 行判 `gameMode === "bossFormation"` 创建 formationDirector —— **已被覆盖为 "boss"，跳过**
5. 第 8626 行 else 分支：`new BossController("thunderGeneral")` 创建 legacy Boss ← 用户看到的内容

**最终修复**（已写入源码 `src/game/Game.ts` 第 8583-8593 行）：

```typescript
if (this.gameMode === "bossReactive") {
  this.gameMode = "bossReactive";
} else if (this.gameMode === "strategySlice") {
  this.gameMode = "strategySlice";
} else if ((this.gameMode as string) === "bossFormation") {
  // S3: 保持 bossFormation（不重置为 legacy "boss"）
  this.gameMode = "bossFormation";
} else {
  this.gameMode = "boss";
}
```

新窗口首次加载 + 硬刷新（Ctrl+Shift+R）即可看到 `gameMode: bossFormation`，debug 面板左上 `URL: ?bossFlow=bossFormation...`。

> 上一版交接文档只修了构造函数路由（patch-s3.cjs 步骤 4），没修 initializeThunderGeneralBoss。这是 patch 脚本本身的疏漏，不是 React Strict Mode 问题——硬刷新之前那版一样会进入 legacy Boss。

## 8. 如果还有问题

### 8.1 游戏卡死（V0728001 追加修复）

**诊断结果**：`renderFormationMode` 有数个结构性缺陷，导致三种不同症状：

| 症状 | 根因 | 位置 |
|------|------|------|
| 挥刀时 Crash | `currentSlash.start.x` 访问了不存在的字段（SlashTrail 没有 `.start` 属性） | Game.ts L9370 |
| UI 缺失（刀势/HP/战士/粒子/背景） | renderFormationMode 只画了 Boss+阵势+防线，没有调用 `drawBackground`/`drawParticles`/`renderPlayerCombatLayer`/`drawHpBar`/`drawEnergyBar` | Game.ts L9364-9387 |
| 帧叠加不刷新 | 没有 `ctx.clearRect(0,0,...)` | Game.ts L9364 |
| HP 归零不触发失败 | `updateFormationMode` 没有 HP death check | Game.ts L9324-9338 |

**V0728001 修复**（Game.ts）：

1. `renderFormationMode` 完全重写，加入：
   - `clearRect` + `ctx.save/restore` + 屏震
   - `drawBackground` + `drawTopMist`
   - `drawSlash`（刀光可见）
   - `drawParticles`（粒子可见）
   - `renderPlayerCombatLayer`（战士+主刀气场+副刀视觉+副刀槽）
   - `drawFloatingTexts` + `drawEdgeFlash`
   - `drawHpBar`（左上 HP 条）
   - `drawEnergyBar`（底部刀势条, 刀势 UI）
   - `drawDebugPanel`（debug 面板恢复）
   - Flash 覆盖
2. 挥刀预览修复：`currentSlash.points[0]` 读取起点，`currentSlash.points[last]` 读终点
3. `updateFormationMode` 补全：`updateTexts` + HP death check + `updateSubBlades`
4. `handlePointerDown` / `handlePointerMove` 中 `isMomentumBossMode` 包含 bossFormation
